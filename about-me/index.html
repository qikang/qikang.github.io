西康#

专研 Kubernetes 与 DevOps 方向, 围绕容器编排、CI/CD 与可观测性排障。

技术栈#

容器与编排#

Kubernetes 日常运维,Helm Chart 编写与版本化交付;Docker 作为镜像构建基线,Proxmox 提供底层虚拟化。

CI/CD 与制品#

Jenkins 编排流水线,Harbor 托管镜像,Nexus 统一管理二进制制品,构建产物归档至 MinIO。

中间件与存储#

MySQL / MariaDB / PostgreSQL 关系型存储;Redis 缓存层;Kafka 消息队列;NATS 轻量级消息系统;TDengine 应对时序场景。

可观测性与网关#

Prometheus 指标 + ELK 日志双轨;Nginx 承担反向代理与流量入口;OnlyOffice 提供在线协作。

脚本与自动化#

Python 封装 API、批处理与日常巡检,降低重复劳动。

云平台#

熟悉 AWS、阿里云和华为云的资源编排与运维。
