Docker CLI 和 crictl 的映射#

通用命令映射#

docker clicrictl描述不支持的功能
attachattach连接到一个运行中的容器–detach-keys, –sig-proxy
execexec在运行中的容器里运行一个命令–privileged, –user, –detach-keys
imagesimages列举镜像
infoinfo显示系统级的信息
inspectinspect, inspecti返回容器、镜像或者任务的详细信息
logslogs获取容器的日志–details
psps列举容器
statsstats实时显示容器的资源使用统计信息列:NET/BLOCK/ I/O, PIDs
versionversion显示运行时(Docker, ContainerD, 或者其他)的版本信息

容器生命周期映射#

docker clicrictl描述不支持的功能
createcreate创建一个新的容器
killstop(timeout=0)杀死一个或者多个正在运行的容器–signal
pullpull从镜像仓库拉取镜像或者代码仓库–all-tags, –disable-content-trust
rmrm移除一个或者多个容器
rmirmi移除一个或者多个镜像
runrun在新的容器里运行一个命令
startstart启动一个或多个停止的容器–detach-keys
stopstop停止一个或多个正在运行的容器
updateupdate更新一个或者多个容器的配置CRI 不支持 –restart、–blkio-weight 以及一些其他的资源限制选项

crictl 独有命令#

crictl描述
imagefsinfo返回镜像的文件系统信息
inspectp显示一个或多个Pod的状态
port-forward转发本地端口到 Pod
pods列举pod
runp运行一个新的pod
rmp移除一个或者多个pod
stopp停止一个或者多个正在运行的pod

docker cli / ctr / crictl 三方对照#

功能Docker CLIContainerd CLICrictl CLI
镜像列举docker images [ls]ctr image [ls/list]crictl images [ls]
导出镜像docker save -o app.tar app:1.2.0ctr image export app.tar weiyigeek.top/app:1.2.0
导入镜像docker load -i app.tarctr image import app.tar
拉取镜像docker pull redis:latestctr -n k8s.io images pull docker.io/library/redis:latestcrictl pull redis:latest
上传镜像docker pushctr -n k8s.io images push docker.io/library/redis:latestcrictl push
更改标记docker tag redis:latest weiyigeek.top/redis:latestctr -n k8s.io images tag docker.io/library/redis:latest weiyigeek.top/redis:latest
删除镜像docker rmictr -n k8s.io images rm docker.io/library/redis:latestcrictl rmi
创建容器docker createctr -n k8s.io container create docker.io/library/redis:latest rediscrictl create
创建并运行容器docker runctr run -d –env name=WeiyiGeek application weiyigeek.top/app:1.2.0
查看容器docker psctr -n k8s.io container listcrictl ps
启动容器docker startctr -n k8s.io task startcrictl start
停止容器docker stopctr -n k8s.io task pausecrictl stop
删除容器docker rmctr -n k8s.io container rmcrictl rm
容器详情docker inspect 39d36ef08456ctr -n k8s.io c info 39d36ef08456crictl inspect 39d36ef08456
容器连接docker attachctr -n k8s.io task attachcrictl attach
进入容器docker execctr -n k8s.io task execcrictl exec
stats(状态)docker topctr -n k8s.io task metric 39d36ef08456crictl stats
