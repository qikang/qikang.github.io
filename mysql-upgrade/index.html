MySQL 二进制 5.7.30 升级到 5.7.35

2022年1月19日 · 1 分钟 · 206 字 · 西康
目录

    • 把mysql innodb 的缓存数据写到磁盘，并停止服务。

    • 备份mysql数据
    • 迁移数据至新版本mysql
    • 归档老数据

    • 升级表文件
    • 重启MySQL服务

https://dev.mysql.com/doc/refman/5.7/en/upgrade-binary-package.html

MySQL root密码
8点开始准备远程
上传新版mysql文件

热备份数据#

[root@RJYF-U-314 local]# /usr/local/mysql/bin/mysqldump -hlocalhost -uroot -p123456 --all-databases > all-db.sql

把mysql innodb 的缓存数据写到磁盘，并停止服务。#

[root@RJYF-U-314 local]# /usr/local/mysql/bin/mysql -u root -p --execute="SET GLOBAL innodb_fast_shutdown=0"

停mysql服务#

[root@RJYF-U-314 ~]# /usr/local/mysql/bin/mysqladmin -S /var/lib/mysql/mysql.sock -u root -p shutdown

备份mysql数据#

[root@RJYF-U-314 ~]# cd /usr/local/
[root@RJYF-U-314 local]# mv mysql{,_upgrade_to_5.7.35_bak}
[root@RJYF-U-314 local]# tar -xf mysql-5.7.35-linux-glibc2.12-x86_64.tar.gz
[root@RJYF-U-314 local]# ln -sv mysql-5.7.35-linux-glibc2.12-x86_64 mysql
[root@RJYF-U-314 local]# ll /etc/my.cnf*

迁移数据至新版本mysql#

[root@RJYF-U-314 local]# cp -r mysql_upgrade_to_5.7.35_bak/mysql-files/ mysql/
[root@RJYF-U-314 local]# chown -R mysql.mysql mysql/mysql-files

归档老数据#

[root@RJYF-U-314 local]# tar -zcf mysql_upgrade_to_5.7.35_bak_2022-01-20.tar.gz mysql_upgrade_to_5.7.35_bak/
[root@RJYF-U-314 local]# rm -rf mysql_upgrade_to_5.7.35_bak/

启动服务#

[root@RJYF-U-314 local]# /etc/init.d/mysql.server start

升级表文件#

[root@RJYF-U-314 local]# /usr/local/mysql/bin/mysql_upgrade -S /var/lib/mysql/mysql.sock -u root -p

重启MySQL服务#

[root@RJYF-U-314 local]# /usr/local/mysql/bin/mysqladmin -S /var/lib/mysql/mysql.sock -u root -p shutdown
[root@RJYF-U-314 local]# /etc/init.d/mysql.server start
